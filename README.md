# nonag-reels

A userscript for watching Instagram reels logged out without the login and sign-up nags.

To use it, install a userscript manager such as FireMonkey and open [nonag-reels.user.js](https://raw.githubusercontent.com/arxodeus/nonag-reels/main/nonag-reels.user.js).

The script is written without ampersands, angle brackets, carets, asterisks, backslashes or backticks.

EUPL v1.2 or later.
